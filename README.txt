Установка
python3 -m pip install -r requirements.txt

Запуск
python3 bot.py

Продолжить незавершённое занятие: /resume

Неверно отвеченные слова хранятся в mistakes.db по написанию слова, поэтому перестановка слов не сбивает ошибки
Незавершённые занятия сохраняют сами слова, поэтому /resume продолжает нужную очередь после перестановки списка
«Мои ошибки» повторяет весь список два раза подряд
«Свой уровень» принимает диапазон, например 120-350
Основной словарь — 5000.txt (5100 слов, 11 уровней; последний содержит 100 слов)
«Фразовые глаголы» использует первые 100 позиций PHaVE Frequency Ranking по COCA
Каждый вопрос автоматически отправляет кешированное аудио и проигрывает его на хосте
Используется только онлайн-озвучка gTTS с кэшем в audio/online, привязанным к написанию слова
При отсутствии записи бот создаёт и сохраняет её онлайн; при недоступности сервиса сообщает об отсутствии голоса
Пополнить недостающий онлайн-кеш: python3 cache_all_audio.py
В настройках можно отключить отправку голосовых, звук на хосте останется включён
«Не знаю» добавляет слово в отдельную карточку, где его можно удалить вручную
