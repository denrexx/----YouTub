# Бот для изучения английских слов

Тренажёр в Telegram: 5100 английских слов и 100 фразовых глаголов, проверка знаний, повторение ошибок и озвучка.

## О словаре

Слова отобраны по частоте употребления в современной английской речи на основе более 20 млн слов из субтитров YouTube и TikTok. Средний год публикации видео составляет 2024,3, медианный год 2025. Из каждой группы однокоренных слов оставлена наиболее частотная форма.

## Запуск

1. Установите Python-зависимости: `python3 -m pip install -r requirements.txt`.
2. Скопируйте `config.example.py` в `config.py` и вставьте токен Telegram-бота.
3. Запустите `python3 bot.py`.

Бот использует только онлайн-озвучку gTTS с кэшем в `audio/online/`, привязанным к написанию слова. Если записи нет, бот создаёт и сохраняет её онлайн. Для преобразования аудио нужен `ffmpeg`. При недоступности сервиса бот сообщает об отсутствии голоса.

Пополнить кэш для актуального списка: `python3 cache_all_audio.py`.

Прогресс и список ошибок сохраняются локально в `progress.json` и `mistakes.db`.
